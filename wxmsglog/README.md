# 微信消息存档

把手机上的微信通知**全部存到本地**，然后一键复制成带日期分组的纯文本，粘给 AI 做总结。

## 为什么是「通知」而不是「聊天记录」

微信的聊天数据库在 `/data/data/com.tencent.mm/`，只有 root 才能读到，而且加密。任何声称能导出你本地聊天记录的非 root 方案，要么是骗人，要么是在上传你的数据。

这个 App 走的是另一条路：**安卓系统本身允许应用读取通知**（NotificationListenerService，需要你手动授权一次）。微信每来一条消息，系统都会把通知内容交给已授权的应用，这就是数据来源。

代价是清楚的：

- 只能拿到**通知里显示的内容**，微信设成「不显示消息详情」时就只有「你收到 2 条消息」
- **装之前的历史拿不到**，从开启那一刻起才开始记
- 微信自己把多条消息合并成一条通知时，能拿到几条取决于它合并的方式（优先解析 MessagingStyle，能拿到多条）

## 隐私

**没有申请 `INTERNET` 权限。** 这不是承诺，是可验证的：安卓在系统层面就不会给没有这个权限的应用建立任何网络连接。你可以用任何 APK 分析工具查清单文件确认。

所有数据存在应用私有目录的 SQLite 里，卸载即清除。

## 怎么用

1. 装好后打开，点「开启通知使用权」，在系统列表里找到「微信消息存档」并打开
2. 回桌面，让微信来几条消息
3. 回到 App，列表里就能看到

**三个按钮：**

- **复制全部** —— 全部记录，按日期分组，进剪贴板
- **复制今天** —— 只要今天的
- **更多** —— 导出到「下载」目录（`.txt`，完整不截断）、分享文本（可发到微信文件传输助手，在电脑上接着用）、记录所有应用、清空

点列表里任意一条，单独复制那一条。长按文字可以直接选中其中一部分。

## 复制出来长什么样

```
微信消息记录，共 128 条

## 2026-10-25
[09:12] 张三: 明天的会改到下午三点
[09:30] 产品群: 李四: 那个方案我看过了，没问题
[10:02] 张三: 记得带上合同

## 2026-10-24
[21:15] 王五: 收到
```

按日期分组是为了让 AI 能理解「哪天聊了什么」，比一整坨流水文本好得多。

## 保活

安卓的省电策略会杀后台。如果发现漏记：

1. 手机设置 → 应用 → 微信消息存档 → 电池 → 设为**不限制**
2. 允许**自启动**（国产 ROM 一般在「权限管理」里）
3. 多任务界面里把它**锁定**

通知监听服务比普通后台服务存活率高得多（系统自己会拉起），但国产 ROM 仍然可能干掉它。

## 自己编译

仓库里带 GitHub Actions，push 就会自动编译：

**Actions → 编译 APK → 跑完在 Artifacts 里下载 `WxMsgLog`**

本地编译需要 JDK 17 + Android SDK 35：

```bash
gradle app:assembleRelease
```

## 技术实现

| 部分 | 做法 |
|---|---|
| 监听 | `NotificationListenerService`，`exported="true"` + `BIND_NOTIFICATION_LISTENER_SERVICE` 保护 |
| 解析 | 优先 `NotificationCompat.MessagingStyle` 取多条消息（精确时间戳）；否则退回 TITLE + BIG_TEXT / TEXT_LINES |
| 去重 | 按「发信人 + 内容 + 时间」算 SHA-1 做唯一索引，`INSERT OR IGNORE`。微信会反复更新同一个通知，不去重会存成十几条 |
| 存储 | `SQLiteOpenHelper`，单表，不引 Room / KSP |
| 导出 | MediaStore 写入「下载」目录，API 29+ 无需存储权限 |
| 剪贴板 | 超过 40 万字符会截断并提示，完整内容走导出 |

## 已知限制

- 微信关闭「通知显示消息详情」时，只能记录到「你收到 N 条消息」
- 图片、语音、表情在通知里本来就没有内容，只能记录到「[图片]」这类占位
- 撤回的消息拿不到
- 被系统拦下的通知（比如你在系统里静音了微信）不会触发监听
